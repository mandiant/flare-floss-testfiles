# test-rust-cryptify

Strings encrypted with the cryptify crate's encrypt_string! macro, using the crate's default key.

Adapted from [rust-deobf](https://github.com/VAHPEM/rust-deobf) (`bench_src/cryptify_default`), by Ve (VAHPEM),
licensed under the Apache License 2.0.

Built with rustc 1.97.0, release profile (stripped), for i686-pc-windows-gnu, x86_64-pc-windows-gnu
(with mingw-w64), and x86_64-unknown-linux-gnu: `make all`.
